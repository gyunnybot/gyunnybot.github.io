## 리스코프 치환 원칙
아래 예시에서 Square 클래스는 Rectangle 클래스의 자식이다.

```java
public class Rectangle {
    protected int width;
    protected int height;

    public void setWidth(int width) { this.width = width; }
    public void setHeight(int height) { this.height = height; }
    public int getArea() { return width * height; }
}

public class Square extends Rectangle {
    @Override
    public void setWidth(int width) {
        this.width = width;
        this.height = width;
    }

    @Override
    public void setHeight(int height) {
        this.width = height;
        this.height = height;
    }
}
```

<br>
Rectangle 클래스를 구성(Composition) 혹은 파라미터로 받는 코드는 다형성에 의해 Square 타입도 받을 수 있는데, 이때 set() 메서드를 사용하면 가로세로가 자동으로 같아지는 문제가 발생한다.

수학적으로는 정사각형이 직사각형에 포함되는 것이 맞지만 프로그래밍 상속 관계에서는 직사각형의 규격을 정사각형으로만 축소하는 결과를 가져온다.

리스코프 치환 원칙이란, 부모 클래스의 명세(약속)를 자식 클래스가 파괴/위반하지 않아야 한다는 약속이다.

해당 원칙은 인터페이스와 의존성 주입으로 지킬 수 있다. 공통적인 명세만 인터페이스에 정의 후 나머지 명세는 각 클래스에서 구현하도록 한다. 사용하는 쪽은 인터페이스에 의존하도록 정의한다.

```java
// 1. 공통 행위(넓이 계산)만 인터페이스로 추출
public interface Shape {
    int getArea();
}

// 2. Rectangle은 Shape을 구현, 독립적인 width/height를 유지
public class Rectangle implements Shape {
    protected int width;
    protected int height;

    public Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }

    public void setWidth(int width) { this.width = width; }
    public void setHeight(int height) { this.height = height; }

    @Override
    public int getArea() {
        return width * height;
    }
}

// 3. Square는 Rectangle을 상속하지 않고, 자기만의 규칙(변 하나)으로 구현
public class Square implements Shape {
    private int side;

    public Square(int side) {
        this.side = side;
    }

    public void setSide(int side) { this.side = side; }

    @Override
    public int getArea() {
        return side * side;
    }
}

// 4. 사용하는 쪽은 구체 클래스가 아니라 Shape 인터페이스에 의존
public class AreaCalculator {
    private final Shape shape; // 구성 (Composition)

    // 생성자를 통해 외부에서 구현체를 주입받음 (DI)
    public AreaCalculator(Shape shape) {
        this.shape = shape;
    }

    public int calculate() {
        return shape.getArea();
    }
}

public class Main {
    public static void main(String[] args) {
        Shape rectangle = new Rectangle(5, 10);
        Shape square = new Square(5);

        AreaCalculator calc1 = new AreaCalculator(rectangle);
        AreaCalculator calc2 = new AreaCalculator(square);

        System.out.println(calc1.calculate()); // 50
        System.out.println(calc2.calculate()); // 25
    }
}
```
