## 리스코프 치환 원칙
아래 예시에서 Square는 Rectangle의 자식 클래스이다.

```java
public class Rectangle {
    protected int width;
    protected int height;

    public void setWidth(int width) { this.width = width; }
    public void setHeight(int height) { this.height = height; }
    public int getArea() { return width * height; }
}

public class Square extends Rectangle {
    @Override
    public void setWidth(int width) {
        this.width = width;
        this.height = width;
    }

    @Override
    public void setHeight(int height) {
        this.width = height;
        this.height = height;
    }
}
```

```java
void resize(Rectangle r) {
    r.setWidth(5);
    r.setHeight(4);
    assert r.getArea() == 20;
}

resize(new Rectangle()); // 통과
resize(new Square());    // setHeight(4)가 width도 4로 바꿔서 실패
```

<br>
resize() 메서드는 Rectangle을 파라미터로 받으므로 다형성에 의해 Square도 받을 수 있다. 컴파일은 정상적으로 수행되지만 Rectangle이 암묵적으로 정의한 규약 \'가로와 세로는 서로 독립적으로 변경된다\'를 Square가 위반해 런타임에 메서드 수행 결과가 기대와 달라지는 문제가 발생한다.

수학적으로는 정사각형이 직사각형에 포함되지만 프로그래밍에서의 상속은 행위(behavior)의 호환성을 기준으로 판단한다. 가로와 세로를 따로 바꿀 수 있는 가변(mutable) 행위를 Square는 제공할 수 없으므로 올바른 하위 타입이 아닌 것이다.

정리하면, 리스코프 치환 원칙은 자식 클래스가 부모 클래스의 명세(규약)를 위반하지 않아야 한다는 원칙이다.

해결 방법은 인터페이스 설계에 있다. Square가 Rectangle을 상속하는 대신에 둘의 공통 행위(넓이 계산)만 인터페이스로 추출한다. 각 클래스는 자신의 규칙에 맞게 구현하고, 사용하는 쪽은 구체 클래스가 아니라 인터페이스에 의존한다.

```java
// 1. 공통 행위(넓이 계산)만 인터페이스로 추출
public interface Shape {
    int getArea();
}

// 2. Rectangle: 가로/세로를 독립적으로 관리
public class Rectangle implements Shape {
    private int width;
    private int height;

    public Rectangle(int width, int height) {
        this.width = width;
        this.height = height;
    }

    public void setWidth(int width) { this.width = width; }
    public void setHeight(int height) { this.height = height; }

    @Override
    public int getArea() { return width * height; }
}

// 3. Square: Rectangle을 상속하지 않고, 변 하나라는 자기만의 규칙으로 구현
public class Square implements Shape {
    private int side;

    public Square(int side) { this.side = side; }

    public void setSide(int side) { this.side = side; }

    @Override
    public int getArea() { return side * side; }
}

// 4. 사용하는 쪽은 Shape 인터페이스에만 의존
public class AreaPrinter {
    public static void printAll(List<Shape> shapes) {
        for (Shape shape : shapes) {
            System.out.println(shape.getArea());
        }
    }
}

public class Main {
    public static void main(String[] args) {
        List<Shape> shapes = List.of(
            new Rectangle(5, 10),
            new Square(5)
        );

        AreaPrinter.printAll(shapes); // 50, 25
    }
}
```
